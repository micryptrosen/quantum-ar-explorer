# Recording and review guide

The current protected local V8 review movie is 169 seconds, 1920 x 1080,
H.264 at 30 fps, silent with English captions. The [timed script](DEMO_SCRIPT.md)
matches its SRT. Genuine Lens Studio 5.23.2 SPECS 27 Sunlit Outdoor footage uses
CLAD/MCP simulated pinch. QAR-016 has since improved native Details layout and
backing; this protected movie has not been replaced or uploaded by this tranche.

All raw, earlier-candidate, narration-ready and fallback media remain preserved.

For another take, open the real native project in Lens Studio 5.23.2. Verify the
SPECS 27 Interactive preview, Sunlit Outdoor and an even landscape capture size
below 3840 × 2160. Verify the visible preview agrees with the queried runtime
before recording: a saved READY screenshot alone does not establish current state.
Use the built-in recorder and save to a unique owner-authorized local filename.
A recorder click or DONE signal alone does not establish a healthy movie.

Use fresh visible control discovery and ordinary coordinate-pinch selection as
described in [Open and test](OPEN_AND_TEST.md). This verified route differs from
LEAF simulated IK, an ordinary Windows mouse click and physical hand tracking.
Ordinary Windows mouse activation remains unresolved in this environment.
Keep scientific sampling normal. Never retake to obtain a preferred random
outcome, invoke scientific callbacks, or put test overlays in demonstration footage.

Begin with equal odds, a common operation, changed predictions and actual confirmation.
Then show the bit, preparation, prediction, measurement, repeat versus fresh trials,
brief manual placement, challenge and optional phase comparison. Record actual
observations; a finite batch need not be evenly divided. Allow the comparison's
mode boundary to settle before choosing a newly discovered restored control.
Use only supported preview-camera movement; keep the station world transforms
fixed except during deliberate manual placement/Recenter.

Check the saved file with a real codec probe and full decode. Inspect actual
encoded frames at state changes, compare captions with visible predictions,
results and counts, and check privacy and framing. Keep the full native frame,
ordinary playback speed and an explicit label for reordered excerpts. Place
English captions in added margins. Preserve every rejected candidate and record
why a later cut is preferred. A still image cannot substitute for recorded interaction.

No authorized recorded narrator was available for this tranche. No voice service,
synthetic speech, music purchase, installation or platform upload occurred.
Any later narration and the actual final video require owner review. The owner
uploads approved media, supplies the real public URL, confirms legal/rights and
eligibility details, and personally submits Devpost. Physical-device performance,
comfort, hand tracking and additive-display contrast remain untested.
