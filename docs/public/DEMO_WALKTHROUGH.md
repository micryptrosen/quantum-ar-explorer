# Preview demonstration outline

Target duration: **2 minutes 45 seconds**, leaving room below the competition's
[three-minute video limit](https://learn-specs.devpost.com/resources). Record the
actual Lens Studio preview. A recording and upload are separate owner actions;
this outline does not represent an uploaded entry.

| Time | Show | Explain |
|---|---|---|
| 0:00–0:15 | The laboratory and its manual placement label | A beginner can explore a single qubit in their own space. Placement is manual; no table recognition is claimed. |
| 0:15–0:35 | Meet the Bit; select Switch 0 / 1 | A classical bit has a definite value of 0 or 1. |
| 0:35–1:00 | Meet the Qubit; prepare 0, 1, then equal superposition | The sphere is a mathematical state diagram. North is 0, south is 1; equal superposition has 50% Z-measurement probability for each result. |
| 1:00–1:40 | Make a Measurement; measure, repeat without preparing, then prepare again | The displayed result is definite. Repeating a measurement of the collapsed state keeps that result. A fresh preparation starts a new trial. |
| 1:40–2:00 | Run ten fresh trials through the additional experiment controls | Counts accumulate; ten independent trials are not guaranteed to split five and five. This is a classical simulation. |
| 2:00–2:25 | Challenge feedback, correct answer, completion, Restart | The experience explains a misconception, rewards understanding and can start again with cleared counts. |
| 2:25–2:45 | Reposition, move the preview camera slightly, then Recenter | The station stays in world space until deliberately moved. Selection uses the supported preview interaction; physical glasses comfort remains untested. |

Before recording, refresh the preview, run the native LEAF scenarios, check that the
whole station and text are visible, and rehearse once without narration. Keep
private editor panels, account details, logs, keys and machine configuration out
of the recording. The public planning brief can be shown briefly if time permits.

Use the supported mouse/pinch simulation for selections. Desktop camera movement
is a demonstration tool; the lesson itself is designed around supported SIK/UIKit
hand selection without a keyboard or handheld controller.
