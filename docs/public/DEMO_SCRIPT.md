# Demonstration narration and shot list

Target: **2:45**, with a 15-second margin below three minutes. This is a timed
script, not evidence of a recorded or uploaded video. Use genuine Lens Studio
preview footage. Read naturally and leave time for the indicated selections.

| Time | Genuine preview actions | Narration |
|---|---|---|
| 0:00–0:15 | Begin at the complete teaching station. Keep the manual placement label visible. | “Quantum AR Explorer turns a familiar space into a miniature quantum laboratory. It helps someone with no quantum background discover the ideas by experimenting. This is the real SPECS preview in Lens Studio. Placement is manual.” |
| 0:15–0:35 | Meet the Bit. Switch 0 / 1, pause on each value, then Next. | “Start with a classical bit. At any moment it has one definite value: zero or one. Switch it, and the value changes. Now let's meet a qubit.” |
| 0:35–1:00 | Prepare 0, then 1, then equal superposition. Pause to show the arrow and probabilities. Continue to measurement. | “This Bloch sphere is a mathematical state diagram, not a particle. Zero points north; one points south. An equal superposition points around the equator. For measurement in this basis, each result has a fifty percent probability. We are simulating one qubit on a classical computer.” |
| 1:00–1:35 | Prepare equal superposition. Measure. Pause on the actual result. Measure again without preparing. | “Before measurement, we have probabilities. Select Measure, and one definite result appears. The state collapses to that result. Measure again without preparing, and it stays the same. Repeatedly measuring a collapsed state is different from starting a fresh experiment.” |
| 1:35–1:55 | Open More controls as needed. Run ten fresh equal-superposition trials. Pause on counters. | “For independent trials, prepare the equal superposition each time. This action does that ten times, and the counters accumulate the results. A small sample need not split five and five. Fifty percent is a probability, not a promise about every group of ten.” |
| 1:55–2:20 | Open the challenge. Choose a wrong answer to show explanatory feedback, then the correct answer. Show completion. | “The challenge checks that distinction. An incorrect answer gets an explanation, so the learner can try again. The correct answer recognizes that fresh measurements are probabilistic. The lesson ends with understanding, not just a score.” |
| 2:20–2:35 | Restart. Open Reposition, move once, then Done. | “Restart clears the experiment for the next learner. Large labeled controls support the preview's simulated selection and the supported hand interaction model. Move the station deliberately to a useful position.” |
| 2:35–2:45 | Slight preview camera movement, then Recenter. Finish on the station. | “The laboratory stays in the world until you move it. Prepare, measure, repeat: quantum ideas become something you can explore. Physical glasses testing remains future work.” |

Do not narrate a predetermined 0 or 1 for a superposition outcome. Let the actual
result appear. Use the current visible labels; open the additional control page
when required. Do not hide a failed selection with a claim it worked. Restart
before another take if the sequence diverges.

At approximately 280 spoken words, delivery around 145 words per minute leaves
time for pauses and selections within the 2:45 target. Only the encoded file's
measured duration can establish the final runtime.
